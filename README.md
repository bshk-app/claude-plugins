# bshk plugins for Claude Code

```sh
claude plugin marketplace add bshk-app/claude-plugins
claude plugin install <plugin>@bshk
```

| Plugin | What it does |
|---|---|
| [rech](plugins/rech) | Dictate prompts by voice and transcribe recordings, on your Mac: GigaAM for Russian, the best local model for other languages. Needs `brew install bshk-app/tap/rech`. |

The plugins are developed in a private monorepo and copied here on release.
